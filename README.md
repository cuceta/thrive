# Thrive

## Overview
Thrive is a wellness and personal growth mobile application built with Flutter. The app is designed to help users build healthy habits, track goals, journal regularly, and monitor personal progress. This project was created as a full product from concept to implementation, focusing on product design, user experience, and mobile development.

 

## Problem
Many habit tracking and journaling apps are either too complicated, too limited, or only focus on one aspect of personal growth. Users often need multiple apps to track habits, write journal entries, and monitor goals. This creates friction and makes it harder for users to stay consistent.

 

## Solution
Thrive combines habit tracking, goal setting, journaling, and progress tracking into one platform. The app focuses on simplicity, clean design, and an engaging user experience so users can easily manage their personal growth in one place.
